Naziv testa: NarudzbaControllerSigurnostTest.csrfStornoJeOdbijen
Prijetnja: zahtjev s kolačićem bez Bearer tokena mijenja tuđu narudžbu.

1. Dohvati Anin Keycloak token i napravi POST /api/narudzbe.
2. Zapiši id nove narudžbe.
3. Pošalji DELETE /api/narudzbe/{id} bez Authorization zaglavlja, uz
   Cookie: SESSION=neki-token i Origin: http://localhost:18081.
4. Očekuj 401 ili 403. S Aninim Bearer tokenom potvrdi da narudžba i dalje postoji.

API prihvaća samo Bearer token. Cookie se ne koristi za autentikaciju.
